# Instructions for coding agents

Read `research/PLAN.md` before doing anything in this repository. It is binding: it says what is worked on,
in which order, and what is paused. Name the plan item your work belongs to before starting; do not work on
or propose paused items unless the user asks for one by name. Then read `research/LOG.md` for where the
research stands, and keep it up to date. `CLAUDE.md` says the same for Claude Code.
