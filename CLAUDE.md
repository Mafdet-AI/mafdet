# MAFDET

Local LLMs that read and think while you type (llama.cpp underneath, Python app, Windows first).

## The plan comes first (binding for every session)

`research/PLAN.md` says what is worked on, in which order, and what is paused. It is imported below, so
every session has it. Follow it: name the plan item before starting any work, do not work on or propose
paused items unless the user asks for one by name, and say so when a request falls outside the plan.
The plan changes only when the project's owner asks.

@research/PLAN.md

## The research log

Before research or engine work, read `research/LOG.md`: where the research stands, what was measured and
what is next. Keep it up to date as the work goes (results, decisions, the next step). Where the LOG's
"Next" list and the plan disagree, the plan wins.
